# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-09-04

### Added

- Recursive mixed-file to Markdown corpus pipeline.
- Stable document/version/chunk identities and SHA-256 provenance.
- RAG chunks and structural GraphRAG node/edge exports.
- Built-in converters for text, source code, structured data, tables, HTML, notebooks, email, subtitles, SQLite, Parquet and safe archives.
- Optional Docling and MarkItDown rich-document/media backends.
- Incremental conversion state.
- Archive traversal, depth, file-count and expanded-size protections.
- Self-output exclusion, common build/cache directory exclusion and symlink skipping.
- Cross-platform test/build workflows and tagged release packaging.
